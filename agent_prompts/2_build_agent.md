작업 폴더: <day2_vibe 절대 경로>
사용자 지시: "PLAN.md대로 exXX 만들기"

너는 이 폴더의 Claude Code임. 먼저 <day2_vibe>\CLAUDE.md를 읽고 그 규칙을 그대로 지킬 것.
자동 실습이라 사용자에게 물을 수 없음. CLAUDE.md의 확인 지점은 "예"로 보고 진행하고, 무엇을 물었을지 보고에 적을 것.
PLAN에 없는 패키지는 설치하지 말 것. 설치는 <day2_vibe>에서 npm.cmd install <패키지>.
환경: Windows, Python 없음. 3000 포트 사용 가능(끝나면 반드시 끌 것).
보고(한국어): 확인받았을 목록 · PLAN 항목별 반영 위치 · 지운 것 · npm run build 결과 · 추가로 보인 점.
